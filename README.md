# weather-app
In this project, I have learnt and used the following methods. I found these very crucial for building a standard, full-frontend project:
-> DOM Manipulation: DOM manipulation is the process of using programming languages—most commonly JavaScript—to interact with and modify a webpage's structure, styling, and content dynamically in the browser. It reduces the need for reloading the webpage to see the new content.
-> Used two event listeners: 1. To allow the user to enter the city name, 2. To check the weather in the city user has provided
-> Error Handling: I have used an error handler which catches the both errors- API limits and Users' Internet connection.

Summary of the project:
This is a demonstrative project on web scrapping from an API key. It fetches realtime and almost perfect weather conditions of the user provided city.
